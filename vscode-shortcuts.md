# VS Code Keyboard Shortcuts (Ubuntu / Linux)

Default keybindings. `Ctrl` = Control, `Shift`, `Alt`. Press `Ctrl+K Ctrl+S` to open the full Keyboard Shortcuts editor and customize any of these.

## Editing Lines (the ones you asked for)

| Action | Shortcut |
|---|---|
| **Duplicate line down** (copy line below) | `Shift+Alt+Down` |
| **Duplicate line up** (copy line above) | `Shift+Alt+Up` |
| **Remove line** (delete whole line) | `Ctrl+Shift+K` |
| **Move line up** | `Alt+Up` |
| **Move line down** | `Alt+Down` |
| Insert line below | `Ctrl+Enter` |
| Insert line above | `Ctrl+Shift+Enter` |
| Select current line | `Ctrl+L` |
| Toggle line comment | `Ctrl+/` |
| Toggle block comment | `Shift+Alt+A` |
| Indent line / selection | `Ctrl+]` |
| Outdent line / selection | `Ctrl+[` |
| Format document | `Shift+Alt+F` |

## Tips

- If a shortcut does nothing, another app or the Ubuntu desktop may be capturing it (e.g. `Ctrl+Alt+Up/Down` is often used for workspace switching). Change it in Settings → Keyboard, or rebind it in VS Code.
- Check any shortcut in VS Code with `Ctrl+K Ctrl+S` and search for its name.
